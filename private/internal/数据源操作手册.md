## 1. 运价查询数据源 / Freight Rate Sources

### 1.1 ShippingEuro (net ocean 基础海运费)
- **URL 模式**: `https://www.shippingeuro.com/sea-freight/{pol}-{pod}.html`（搜索结果页）
- **搜索策略**: web_search `site:shippingeuro.com {POL} to {POD} container rate`
- **提取字段**: 船公司、船名航次、ETD、40HQ 运价(USD)、有效期
- **口径**: net ocean，仅含基础海运费，不含 BAF/FAF/OTHC/DOC FEE
- **更新频率**: 每日
- **注意事项**:
  - 页面含多条船公司报价，需逐行解析
  - 有效期为表格中的"Validity"或"有效期"列，格式 `YYYY-MM-DD`
  - 部分航线数据缺失（如中美航线较少），此时需切换其他数据源

### 1.2 Flexport Atlas (all-in 报价)
- **URL 模式**: `https://www.flexport.com/atlas/route/{pol}-{pod}/`
- **搜索策略**: web_search `site:flexport.com/atlas {POL} {POD} freight rate`
- **提取字段**: 船公司、运价区间(USD)、更新日期
- **口径**: all-in，含 BAF/FAF/DOC FEE 等常见附加费
- **更新频率**: 每日
- **注意事项**:
  - Flexport 为美国公司，中美航线数据较全，中国出口数据可能不如国内平台
  - 报价通常为区间值（low-high），非精确单点
  - 页面含 JS 渲染组件，`web_fetch` 可能不完整，需结合搜索结果摘要

### 1.3 Drewry WCI (世界集装箱运价指数)
- **URL**: `https://www.drewry.co.uk/supply-chain-advisory/supply-chain-expertise/world-container-index-assessed-by-drewry`
- **搜索策略**: web_search `Drewry WCI container freight rate index {route} {date}`
- **提取字段**: 指数值(USD/40FT)、周环比变化
- **口径**: 综合指数，含基础海运费+附加费的市场均价
- **更新频率**: 每周四
- **注意事项**:
  - 指数非实际运价，是市场均价，用于判断趋势
  - 仅有 8 条主干航线
  - 部分内容需要付费订阅，公开页面仅展示摘要

### 1.4 Skypace / Container News (市场参考价)
- **URL 模式**: `https://container-news.com/` 或 `https://skypace.com/`
- **搜索策略**: web_search `{POL} {POD} spot freight rate {month} {year} container`
- **提取字段**: 价格区间(USD)、日期、市场趋势描述
- **口径**: net ocean 或市场参考价（需标注）
- **更新频率**: 不固定
- **注意事项**:
  - 数据可能为文章引用而非实时报价
  - 国际网站，英文搜索效果更好
  - 需人工判断来源可信度

### 1.5 搜航网 / SoFreight（国内运价聚合）
- **URL**: `https://www.sofreight.com/`
- **搜索策略**:
  - **首选**: web_search `{起运港} {目的港} 海运费 sofreight`（通用搜索，非 site 限定）
  - **备选**: web_search `搜航网 {起运港} {目的港} {柜型} 运价`
  - **降级**: 若上述均未命中，从搜索结果摘要中提取运价信息，放弃深入抓取 sofreight 页面
- **提取字段**: 船公司、运价(USD/RMB)、有效期、船期
- **口径**: 需标注（平台不统一标明 net ocean / all-in）
- **更新频率**: 每日
- **注意事项**:
  - ⚠ **已知问题**: `site:sofreight.com` 限定搜索可能被跳转至第三方页面，优先使用通用搜索+结果摘要提取
  - 国内货代常用平台，中文界面，中国出口航线数据较全
  - 若通用搜索也返回第三方跳转结果，直接降级到其他数据源（JCTrans / 维运网），不浪费搜索轮次

### 1.6 JCTrans / 锦程物流（运价+资讯）
- **URL**: `https://www.jctrans.com/`
- **搜索策略**:
  - **首选**: web_search `锦程物流 {起运港} {目的港} {柜型} 运价`
  - **备选**: web_search `{起运港} {目的港} 海运费报价 jctrans`
  - **降级**: web_search `{起运港} {目的港} 集装箱 海运费 最新报价`（通用搜索，不加 site/jctrans 限定词，从搜索结果中筛选 jctrans.com 结果）
- **提取字段**: 运价区间、船公司、发布时间
- **口径**: 需标注，多为市场参考价
- **更新频率**: 每日
- **注意事项**:
  - 老牌物流门户，兼有运价行情和行业资讯，报价需交叉验证
  - `site:jctrans.com` 限定搜索命中率不稳定，优先使用品牌名+港口的中文自然语言搜索

### 1.7 上海航运交易所 / SSE（SCFI/CCFI 指数官方源）
- **URL**: `https://www.sse.net.cn/`
- **搜索策略**: web_search `上海航运交易所 SCFI {日期}` 或 `CCFI {日期}`
- **提取字段**: 综合指数、分航线指数、周环比
- **口径**: 集装箱运价指数（市场均价，非实际报价）
- **更新频率**: 每周五
- **注意事项**: SCFI 为即期运价指数，CCFI 为综合指数含长协。用于判断市场趋势，不替代具体报价

### 1.8 Freightos FBX（国际集装箱运价指数）
- **URL**: `https://fbx.freightos.com/`
- **搜索策略**:
  - **首选**: web_search `Freightos FBX container freight index {route} {date}`
  - **备选**: web_search `{route} container spot rate index weekly {YYYY}`（通用搜索，不限 site/freightos，从结果中提取 FBX 指数数据）
  - **降级**: 若 FBX 未命中，改用 Drewry WCI 或 SCFI 替代判断市场趋势
- **提取字段**: 指数值(USD/FEU)、12条主干航线分指数
- **口径**: all-in 运价（含附加费），市场成交价
- **更新频率**: 每周
- **注意事项**:
  - 与 Drewry WCI 并列两大集装箱运价指数，可交叉验证市场趋势
  - 特定航线指数在通用 web_search 中可能不易命中，优先用 FBX 品牌名搜索；若仍无结果，降级到 WCI/SCFI

### 1.9 船公司官网（马士基 / 中远海运）
- **马士基**: `https://www.maersk.com/` / SynHub `https://synconhub.coscoshipping.com/`
- **搜索策略**: web_search `site:maersk.com {起运港} {目的港} schedule` 或 `site:synconhub.coscoshipping.com {航线}`
- **提取字段**: 船期、船名航次、运价（若有公开报价页）
- **口径**: 船公司官方，最权威但公开运价信息有限
- **注意事项**: 船公司官网运价多为询价入口或会员专区，公开抓取受限。优先用于船期核对和港序验证

### 1.10 易港通 / Enorthub（港口物流综合平台）
- **URL**: `https://www.enorthub.com/`
- **搜索策略**: web_search `site:enorthub.com {港口名} 运价 政策`
- **提取字段**: 港口运价行情、政策公告
- **口径**: 需标注
- **注意事项**: 兼有运价和港口政策信息，可作为运价与目的港政策的交叉数据源

### 1.11 维运网 / Weiyun（乐域旗下船期运价综合平台）
- **URL**: `https://www.weiyun001.com/`
- **运营方**: 乐域（Logwing），厦门 | 品牌含维运网、乐域订舱、rediSAIL、CargoAct、集运宝典
- **搜索策略**: web_search `site:weiyun001.com {起运港} {目的港} 运价` 或 `维运网 {船公司} {航线} 船期`
- **提取字段**: 运价(USD/RMB)、船公司、船期、热门航线排行榜（周/月/季榜）、航线趋势分析
- **口径**: 需标注（"维运优选"报价，11家供应商提供 7357+ 条运价），登录后可查看完整运价
- **更新频率**: 每日
- **功能覆盖**: 船期查询、船舶定位、货物跟踪、拼箱查询、铁路查询、物流大数据
- **注意事项**:
  - 乐域旗下平台，国内货代圈常用，中文界面友好
  - 运价需登录查看完整信息，公开页面仅展示部分
  - 船期排行榜可快速判断热门航线走势
  - 物流大数据中心提供航线趋势即时分析，辅助市场洞察

## 2. 船期/AIS 追踪数据源 / Vessel Tracking Sources

### 2.1 VesselFinder (AIS 实时船位)
- **URL 模式**: `https://www.vesselfinder.com/vessels/{VESSEL_NAME}-imo-{IMO}-mmsi-{MMSI}`
- **搜索策略**: web_search `site:vesselfinder.com {vessel name} IMO {imo}`
- **提取字段**: IMO、当前位置(经纬度)、航速、航行状态、上一港+离港时间、下一港+ETA、AIS 更新时间
- **时效分级**: 看页面显示的 "Position Received: X minutes/hours ago"
  - <1h → [实时]
  - 1-6h → [稍旧]
  - 6-24h → [滞后]
  - >24h → [严重滞后]
- **注意事项**:
  - 免费用户只能看首页基础信息，详细信息（历史轨迹、港口停靠记录）需付费
  - IMO 号是最精确的查询方式，船名可能重名
  - 中文船名直接搜无结果，必须用英文船名

### 2.2 MarineTraffic (AIS 实时船位)
- **URL 模式**: `https://www.marinetraffic.com/en/ais/details/ships/imo:{IMO}`
- **搜索策略**: web_search `site:marinetraffic.com {vessel name} IMO`
- **提取字段**: 同上（VesselFinder 和 MarineTraffic 数据源类似）
- **注意事项**:
  - 免费用户有每日查询限制
  - 部分页面需要登录，优先用 VesselFinder

### 2.3 MyShipTracking (AIS 备选)
- **URL 模式**: `https://www.myshiptracking.com/vessels/{vessel-name}-imo-{imo}`
- **搜索策略**: web_search `site:myshiptracking.com {vessel name} IMO`
- **用途**: 当 VesselFinder / MarineTraffic 都不可用时作为备选

### 2.4 SeaRates / 船公司官网（港序数据，非实时 AIS）
- **URL 模式**: `https://www.searates.com/` 或船公司官网 schedule 页
- **搜索策略**: web_search `{vessel name} {voyage} port rotation schedule`
- **提取字段**: 计划港序、计划 ETA/ETD
- **标注**: 必须标 `[港序]` + "非实时船位，为船公司计划港序"
- **注意事项**:
  - SeaRates 港序数据≠实时 AIS，是船公司公布的船期表
  - 禁止将港序数据的"下一港"当作实时船位
  - 若同时有 AIS 数据，并排对比展示

### 2.5 船讯网 / ShipXY（国内 AIS 平台，含 API 服务）
- **URL**: `https://www.shipxy.com/`
- **API 门户**: `https://api.shipxy.com/`
- **API 文档**: `https://apidocs.shipxy.com/`
- **搜索策略**: web_search `site:shipxy.com {船名} IMO {imo}` 或 `船讯网 {船名} 船位`
- **提取字段**: 船名、IMO/MMSI、当前位置、航速、航向、目的港、ETA、AIS 更新时间
- **时效分级**: 同 VesselFinder 标准（<1h 实时 / 1-6h 稍旧 / 6-24h 滞后 / >24h 严重滞后）
- **API 最优解清单**（按业务场景推荐调用链路）:
  - **实时船位**: `船舶AIS实时船位` — 通过 MMSI 查询单船实时位置/航速/航向/目的港/ETA，7×24 毫秒级延迟
  - **历史轨迹**: `船舶历史轨迹查询` — 按 MMSI + 时间范围查询完整航迹点序列，基于 15 年历史轨迹仓库
  - **挂靠记录**: `船舶挂靠查询` — 按船舶/港口维度追溯历史停靠及靠离时间，含当前挂靠状态
  - **船队监控**: `区域船AIS实时数据` — 按经纬度矩形区域获取范围内所有船舶实时数据，建议单次区域范围 ≤ 0.5°
  - **推送服务**: 最新船位推送 / 到离港事件推送 / 区域电子围栏推送 — 通过 TCP/IP 主动推送，适用于船队动态监控
  - **档案查询**: 基础档案数据（船籍/载重吨/船级社/PSC检查）+ 历史档案数据
  - **气象水文**: 港口潮汐 / 台风数据 / 海区预报 / 全球气象
- **接入方式**: HTTP API（需申请 API Key）/ SDK（多语言）/ MCP 协议
- **技术指标**: 2003 年成立，15 年历史数据，10 亿+ 实时数据，150+ AIS 卫星，5000+ 北斗定位
- **注意事项**:
  - 中文界面，国内用户友好，中文船名搜索效果优于英文平台
  - 覆盖中国近海及主要国际航线，与 VesselFinder 互补
  - 部分数据可能滞后于 VesselFinder，建议双源交叉验证
  - API Key 需在 api.shipxy.com 申请，未注册用户仅可使用网页搜索
  - 多船查询上限 100 条/次，区域船舶查询建议范围 ≤ 0.5° 矩形
  - 智能算法内置船舶行为识别、智能挂靠分析及航次提取，直接返回结构化数据

## 3. 汇率数据源 / Exchange Rate Sources

### 3.1 中国银行外汇牌价
- **URL**: `https://www.boc.cn/sourcedb/whpj/`
- **搜索策略**: web_search `中国银行外汇牌价 {币种} 现汇买入价 现汇卖出价`
- **提取字段**: 货币对、现汇买入价、现汇卖出价、发布日期
- **更新频率**: 仅工作日（周一至周五），周末/节假日不更新
- **注意事项**:
  - 周末查询时强制标注"⚠ 今日为周X，汇率为最近工作日牌价"
  - 非主流币种（如 AED）按"每100单位"计价，需换算标注
  - 交叉汇率（如 AED→EUR）需经人民币两步套算

### 3.2 XE.com（备用交叉验证）
- **URL**: `https://www.xe.com/currencyconverter/`
- **搜索策略**: web_search `XE.com USD CNY exchange rate {date}`
- **用途**: 当 BOC 牌价疑似异常时交叉验证
- **注意事项**: XE 为中间市场汇率，非银行实际交易价，标注"中间市场参考价"

## 4. 目的港政策数据源 / Destination Port Policy Sources

### 4.1 SeaRates 目的港信息
- **URL 模式**: `https://www.searates.com/port/{port_code}/`
- **搜索策略**: web_search `site:searates.com/port {port name}`
- **提取字段**: 港口基本信息、免堆期、VGM 要求、危险品申报规则
- **数据质量**: 中等，免堆期数据可能不准（多源冲突时对比验证）

### 4.2 各国海关官网
- **搜索策略**: web_search `{country} customs import policy {commodity} tariff`
- **提取字段**: 关税税率、VAT、特殊单证要求、禁止进口品类
- **区域特定来源**:
  - 美国: CBP.gov、USITC HTS
  - 欧盟: EU TARIC、各成员国海关
  - 阿联酋: Dubai Customs、Federal Customs Authority
  - 尼日利亚: Nigeria Customs Service、SON
  - 日本: Japan Customs
- **注意事项**: 海关网站多为政府域名，部分在中国内网访问可能受限

### 4.3 物流资讯平台
- **搜索策略**: web_search `{port} free time demurrage detention policy {year}`
- **常用站点**: sczil.com、frtledger.com、shippingazette.com、jctrans.net
- **注意事项**:
  - 多源数据冲突时双列标注（来源A + 来源B），取船公司确认为准
  - 超过 6 个月未更新的政策标注"建议重新确认"

### 4.4 各国检疫标准
- **搜索策略**: web_search `{country} ISPM15 fumigation requirement wood packaging`
- **提取字段**: ISPM15 强制/可选、熏蒸证书要求、食品检疫
- **注意事项**: NPPO（国家植物保护组织）官网最权威，但通常无中文

### 4.5 海关总署（中国进出口政策）
- **URL**: `https://www.customs.gov.cn/`
- **搜索策略**: web_search `site:customs.gov.cn {目的国} 进出口 政策 公告` 或 `海关总署 检疫要求 {目的国}`
- **提取字段**: 公告标题、发布日期、核心要求摘要
- **注意事项**: 权威性最高，但公告格式不统一，需人工提炼关键条款。对于部分国家可能无专门公告

### 4.6 单一窗口（国际贸易单一窗口）
- **URL**: `https://www.singlewindow.cn/`
- **搜索策略**: web_search `site:singlewindow.cn {目的国} 通关 政策 要求`
- **提取字段**: 通关须知、单证要求、检疫规定
- **注意事项**: 国家级通关服务平台，政策更新及时。与海关总署互补：单一窗口偏操作指引，海关总署偏法规公告

### 4.7 HS编码查询（海关编码速查）
- **URL**: `https://www.hsbianma.com/`
- **搜索策略**: web_search `site:hsbianma.com {商品名} HS编码` 或 `{商品名} 海关编码 税率`
- **提取字段**: HS编码(6位/10位)、商品描述、出口退税率、监管条件
- **注意事项**: 用于目的港清关时快速确定商品编码对应的关税税率和监管要求，辅助目的港政策查询

### 6.2 Ship24（提单号追踪 API）
