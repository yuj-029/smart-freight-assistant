### 测试7：HS编码（知识问答）

提示词：「HS编码是什么东西」

**HS编码 (Harmonized System Code)**：《商品名称及编码协调制度》下的国际贸易商品分类标准。1988年由世界海关组织(WCO)推出，全球200+国家使用，覆盖98%以上贸易量。

| 要点 | 说明 |
|------|------|
| 结构 | 前6位国际统一，各国可扩展（中国10位，美国HTS 10位） |
| 作用 | 决定关税税率、贸易统计、监管分类、原产地判定 |
| 更新频率 | WCO每5年一次全面修订 |
| 重要性 | 归类错误→补税+罚款，故意错报→罚款货值2-4倍 |

| 证书 | 有效期 | 说明 |
|------|-------|------|
| PC (Product Certificate) | 6个月-1年 | 产品注册证书，可复用 |
| SC (SONCAP Certificate) | 单次有效 | 每批货前申请，绑定BL+发票 |
